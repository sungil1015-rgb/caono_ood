# C003 회전 증강 대조 실험

두 모델 모두 강한 색 증강, 144장 배치, 동일 시드, 동일 손실 비율(1:1:1)과 코사인 스케줄 20에폭 목표를 사용했다. 7에폭 가중치를 비교했다. 차이는 90도 단위 회전 증강의 유무다.

각 모델의 정상 임계값은 해당 모델의 `val_normal`로 스텝별 p99 보정했다. 시리얼 단위 부트스트랩으로 정상 PASS 차이의 95% 구간을 구했다. 이 구간은 학습 시드 간 변동은 포함하지 않는다.

| 깊이 | 회전 없음 PASS | 회전 있음 PASS | 회전 없음 우위 | 95% 구간 (장) |
|---|---:|---:|---:|---:|
| bottleneck | 1094/1104 | 1087/1104 | +7 | [1, 13] |
| up2 | 1093/1104 | 1082/1104 | +11 | [3, 19] |
| up1 | 1097/1104 | 1082/1104 | +15 | [6, 25] |

NG는 두 모델 모두 동일한 판정인지 `results.json`에서 확인할 수 있다. 스텝별 차이와 각 모델만 PASS한 이미지 수는 `summary.json`에 있다. NG는 모델 선택에 사용하지 않았고 보류된 test 분할도 사용하지 않았다.
