# Canon 부품 이미지 검사 실험 결과 정리

## 1. 목표와 데이터

입력 이미지의 **기종은 이미 알고 있다**. 검사에서는 촬영 스텝이 맞는지, 그리고 그 스텝에서 보여야 할 부품이나 인쇄 상태가 정상인지 판단해야 한다. 기종 분류는 과제에 포함하지 않았다. 정상 이미지가 대부분이고 NG 이미지는 적으며, 초기 NG 폴더에는 결함 원인이나 라벨이 불명확한 사진도 있었다. 이 때문에 첫 단계에서는 정상 데이터만으로 학습하는 STFPM을 사용했고, 이후 작은 결함을 더 자세히 보기 위해 ROI 검출과 정상 스텝 간 대조학습을 추가했다.

원본 목록은 13개 기종, 3,216대, 47,255장이다. 정상 경로에서 이미지가 1,000장 이상인 6개 기종을 골라 NG 표시 시리얼을 제외하면 **3,124대, 45,728장**이다. 기종 안에서 시리얼 이름순으로 나눈 분할은 train 60%, `val_normal` 10%, `val_step` 10%, test 20%이며 같은 기기의 사진은 한 분할에만 들어간다. 실제 사진 수는 각각 **27,402 / 4,568 / 4,581 / 9,177장**이다. 세부 수량은 [데이터 분할](../../../data/experiment_v1/summary.json)에 있다.

이후 ROI 대조학습은 데이터 전체가 아닌 `3029C003AA`(이하 C003)와 `3029C009AA`(C009)의 **스텝 1~12**에 집중했다. 스텝 0은 이 OOD 실험 대상에서 제외했고, 13·14도 사용하지 않았다. C003의 `val_step`에서는 검출기 학습에 포함된 시리얼 3대, 36장을 제외했다. 따라서 최신 C003 ROI 평가의 `val_step`은 **92대 × 12스텝 = 1,104장**이다.

## 2. 원본 이미지 기반 첫 파이프라인

처음에는 기종별 **ImageNet 사전 학습 ResNet18 스텝 분류기**로 스텝을 예측하고, 기종·스텝별 **ResNet18 STFPM**으로 이상 점수를 계산했다. 분류기와 STFPM은 90도 단위 회전 증강을 사용했다. 공정에서 예상 스텝을 알면 예측한 스텝과 예상 스텝이 일치하고 해당 STFPM도 정상으로 수용할 때 PASS하도록 구성했다. 원본 단계에서는 별도 부품 crop을 사용하지 않았다.

설정을 고정한 뒤 평가한 6개 기종의 **test 627대·9,177장** 결과는 다음과 같다. 이 분할의 NG 표시가 없는 이미지를 정상으로 간주한 수치다.

| 평가 항목 | 결과 |
|---|---:|
| 스텝 분류 정답 | 9,072/9,177장, **98.86%** |
| 정답 스텝 STFPM의 정상 수용 | 9,158/9,177장, **99.79%** |
| 스텝 일치와 STFPM 수용을 모두 만족 | 9,055/9,177장, **98.67%** |
| 모든 스텝을 PASS한 기기 | 515/627대, **82.14%** |

그러나 STFPM만으로 다른 스텝을 구별하는 능력은 약했다. 별도의 전체 `val_step` 4,581장을 각 기종의 모든 STFPM에 넣었을 때, ResNet18 STFPM은 **틀린 스텝 후보의 22.59%만 거절**했다. 한 사진에서 여러 스텝이 동시에 PASS한 경우가 4,574장이었다. 따라서 당시 스텝 판정은 별도 분류기에 의존했다. 초기 NG 폴더의 평가 가능한 11장에서는 STFPM 단독 FAIL이 1장, 스텝 불일치까지 포함한 최종 FAIL이 3장이었다. 이 NG 폴더의 라벨이 일관되게 확정된 것은 아니므로 검출률로 해석하지 않았다. 원본 파이프라인 수치는 [test 요약](../../../data/experiment_v1/results/test_summary.json), [교차 스텝 결과](../../../data/experiment_v1/results/stfpm_cross_step_summary.json), [NG 평가](../../../data/experiment_v1/results/ng_evaluation.json)에 있다.

이 단계에서 확인한 핵심은 **정상 수용률이 높아도 다른 스텝이나 작은 문자 누락을 거절한다는 보장은 없다**는 점이다. STFPM 이상점수 지도와 NG 비교에서도 흰 배경의 공통 특징이 많고, 미세한 각인 차이가 정상 점수 범위에 들어오는 사례가 있었다.

## 3. ROI 검출과 입력 구성

부품 위치 라벨이 있는 일부 사진으로 COCO 사전 학습 **Faster R-CNN ResNet50 FPN v2**를 학습했다. 학습용 박스 라벨은 181장, 홀드아웃은 65장이며 20에폭 결과 홀드아웃의 점수 0.25·IoU 0.5 기준 정답 클래스 박스 검출은 **65/65장**이었다. 별도 400장 시험에서는 스텝 클래스 Top-1이 **349/400장(87.25%)**이고 예측 자체가 없는 사진이 22장이었다. 400장에는 박스 정답 라벨이 없어 위치 IoU나 검출 AP는 계산할 수 없다. [검출기 학습 분할](../../../data/experiment_v1/roi_detector/split.json)과 [400장 결과](../../../data/experiment_v1/roi_detector/test_400/results.json)에 원자료가 있다.

이후 ROI 추출에서는 검출기의 **예측 스텝 클래스를 최종 판정에 사용하지 않았다**. 최고 점수 박스를 선택하고, 점수 0.25 미만 또는 박스가 없으면 `NO_ROI`로 처리했다. 검출기 내부 분류 헤드는 박스 점수 계산에는 여전히 관여한다. 박스 주위 10% 여백을 더해 자르고 비율을 유지한 채 확대해 1024×1024 회색 캔버스에 배치했다. ROI가 없는 학습 사진은 제외하고, 평가 사진의 `NO_ROI`는 PASS로 세지 않았다.

C003 스텝 1~12 학습 사진 **6,840장 중 6,829장**에 ROI가 검출되어 11장이 제외됐다. C009는 **1,920장 중 1,917장**이 검출되어 3장이 제외됐다. C003와 C009의 독립 `val_step` ROI는 각각 **1,104/1,104장**, **324/324장** 검출됐다. 이 수치는 ROI가 발견됐다는 뜻이며, 모든 박스가 부품을 정확히 담았다는 위치 정확도는 아니다. 입력별 박스와 crop은 [ROI 매니페스트](../../../data/experiment_v1/roi_contrastive/manifest.json)에 있다.

## 4. ROI에서 비교한 정상 모델

아래 ROI 모델은 **기종별로 따로 학습**했다. 검증은 해당 사진의 스텝을 알고 있는 조건에서 수행했다. 검출된 `val_normal` 정상 점수의 **스텝별 99백분위(p99)**를 임계값으로 정하고, 학습 정상 ROI 중 임베딩이 가까운 **5장과의 평균 코사인 거리**를 점수로 썼다. `val_step`과 NG는 임계값을 정하는 데 사용하지 않았다. 원본 STFPM의 train 최대 점수 임계값과는 다른 기준이므로 두 수치를 같은 조건의 직접 비교로 보지 않는다.

| 접근 | C003 `val_step` 정상 PASS | C009 `val_step` 정상 PASS | 확인한 점 |
|---|---:|---:|---|
| ROI STFPM | 1,082/1,104 | 313/324 | C009 정상 수용은 높았으나 C009 스텝 3의 확정 NG 2장은 모두 점수 기준 PASS |
| ROI ResNet18 다중 레이어 SupCon, `layer3` | 1,092/1,104 | 304/324 | C003의 정상 수용 개선, C009 큰 각인 누락 1장 FAIL |
| 고정 ResNet18 + U-Net 디코더, 초기 72장 배치 `bottleneck` | 1,092/1,104 | 316/324 | C009 정상 수용 개선, 작은 문자 누락은 PASS |
| 고정 ResNet18 + U-Net 디코더, 144장 배치 `bottleneck` | 1,082/1,104 | 317/324 | C009는 추가 개선, C003은 악화 |

다중 레이어 SupCon은 같은 기종·스텝의 서로 다른 시리얼을 positive, 다른 스텝을 negative로 묶었다. 처음 모델은 ResNet18 `stem`~`layer3` 특징 각각에 손실을 적용했다. U-Net 실험은 이 인코더를 **고정**하고 `layer3→layer2→layer1`을 잇는 디코더와 투영 헤드만 학습했다. 학습 손실은 배치 전체의 positive·negative 관계를 사용했고, 판정에는 학습 정상 특징 저장소와의 거리를 썼다. 세부 비교는 [ROI 대조학습](../../../data/experiment_v1/roi_contrastive/summary.md), [ROI STFPM](../../../data/experiment_v1/roi_stfpm/summary.md), [U-Net 초기 결과](../../../data/experiment_v1/roi_unet_contrastive/summary.md)에 있다.

코사인 거리를 공분산 보정 거리로 바꾸거나, 마할라노비스 거리 기반 SupCon 손실로 다시 학습하는 실험도 했다. 일부 깊이에서 정상 PASS가 몇 장 늘었지만, **작은 문자 누락을 정상 사진과 안정적으로 분리하지는 못했다**. 고정 백본의 전역 레이어 통계만 사용하는 접근도 C009 NG에서 대응 정상까지 함께 FAIL하는 사례가 있었다. 자세한 수치는 [거리 비교](../../../data/experiment_v1/roi_contrastive/covariance_pair_metric/summary.md), [손실 재학습](../../../data/experiment_v1/roi_contrastive/mahalanobis_train/summary.md), [고정 백본 분포](../../../data/experiment_v1/frozen_layer_distribution/summary.md)에 있다.

## 5. 현재 성능 상위 두 모델

C003에서 정상 수용을 우선해 **서로 다른 학습 모델 두 개**를 골랐다. 하나는 회전 없이 색 변화만 적용한 U-Net `up1`, 다른 하나는 ResNet18 전체를 파인튜닝하고 마지막 레이어에서 ROI 패딩을 제외한 평균·최댓값 풀링을 사용한 모델이다.

| 모델 | 학습 구성 | 원래 `val_step` 정상 취급 PASS | C003 기존 NG 폴더 2장 |
|---|---|---:|---|
| **U-Net `up1`** | 고정 인코더 + 학습 디코더, 스텝당 12장·총 144장 SupCon, 7에폭 | **1,097/1,104 (99.37%)** | 점수 FAIL 1장, `NO_ROI` 1장 |
| **ResNet18 `last`** | 전체 파인튜닝, ROI 마스크 평균·최댓값 풀링, 144장 SupCon, 10에폭 | **1,093/1,104 (99.00%)** | 점수 FAIL 1장, `NO_ROI` 1장 |

두 모델의 학습 증강은 90도 회전을 **제외**하고 색 변화 확률 0.85, 밝기·대비 ±0.15, 채도 ±0.08을 사용했다. U-Net의 세 출력 손실은 1:1:1이다. 같은 7에폭·144장 배치·강한 색 증강으로 맞춘 회전 비교에서는 회전 없는 U-Net `up1`이 **1,097/1,104**, 회전 있는 모델이 **1,082/1,104**를 PASS했다. `bottleneck` 손실 비중을 3배로 높인 모델의 `up1`은 **1,086/1,104**였다. 따라서 이 설정에서는 회전 제외와 동일 손실 비율이 더 나았다. 다만 회전 일반화가 필요한 새 촬영 환경까지 검증한 결과는 아니다. [색·손실 비교](../../../data/experiment_v1/roi_unet_contrastive/color_ablation_c003_summary.md), [회전 대조](../../../data/experiment_v1/roi_unet_contrastive/rotation_ablation_c003/summary.md), [ResNet18 비교](../../../data/experiment_v1/roi_resnet18_full_supcon/c003_masked_mean_max/summary.md)에 상세 기록이 있다.

### 모든 스텝에 넣은 교차 시험

C003 `val_step`의 ROI **1,104장**을 각 모델의 스텝 1~12 정상 저장소와 **모두** 비교했다. 자기 스텝 판정 1,104건과 다른 스텝 판정 **1,104×11=12,144건**이다. 학습 저장소와 `val_normal` p99 임계값은 그대로 사용했다.

| 모델 | 자기 스텝 PASS | 다른 스텝 거절 | 다른 스텝 수용 | 자기 스텝만 유일하게 PASS |
|---|---:|---:|---:|---:|
| U-Net `up1` | 1,097/1,104 | **12,143/12,144 (99.992%)** | 1건 | 1,097/1,104 |
| ResNet18 `last` | 1,093/1,104 | **12,143/12,144 (99.992%)** | 1건 | 1,093/1,104 |

두 모델에서 유일하게 다른 스텝을 수용한 경우는 동일한 **`2EQ16854/step_11.jpg`를 스텝 12 기준으로 평가**한 것이다. 이 이미지는 자기 스텝 11에서는 두 모델 모두 FAIL이었다. 사용자가 이번 검토에서 이 사진을 **기존 정상 목록에 섞여 있던 NG**라고 확인했다. 따라서 원래의 `1,104장 정상`이라는 표기는 데이터 라벨 기준의 과거 집계이며, 이 사진을 정상으로 해석한 오경보 1장으로 세면 안 된다.

이 재확인 결과를 반영하면, **확인된 정상 1,103장**에서 U-Net은 **1,097/1,103장(99.46%)**, ResNet18은 **1,093/1,103장(99.09%)**을 자기 스텝에서 PASS했다. 나머지 다른 스텝 입력은 모델별 **12,133/12,133건 전부 거절**했다. 다만 새 NG 사진은 스텝 12 기준에서는 두 모델 모두 PASS했으므로, **스텝을 모르는 상태에서 모든 후보 중 하나라도 PASS하면 정상**이라는 규칙으로는 검출되지 않는다. 공정이 예상 스텝 11을 제공하고 그 스텝으로 판정하면 두 모델 모두 이 NG를 FAIL로 잡는다. 이 차이가 실제 운영 규칙에서 중요하다.

교차 시험의 원본 집계, 12×12 조합표와 이미지별 판정은 [교차 시험 요약](../../../data/experiment_v1/roi_cross_step_top2_c003/summary.md), [전체 결과 JSON](../../../data/experiment_v1/roi_cross_step_top2_c003/summary.json), [이미지별 CSV](../../../data/experiment_v1/roi_cross_step_top2_c003/per_image.csv)에 있다.

## 6. 현재 결론과 해석 범위

현재 C003 스텝 1~12에서는 **ROI 검출 → 기종·예상 스텝의 정상 특징 거리 → 스텝별 임계값** 흐름이 유망하다. 두 상위 모델은 독립 시리얼의 정상 사진 대부분을 수용하면서, 같은 사진을 다른 스텝으로 넣은 경우는 거의 모두 거절했다. 사람이 정상 목록에 넣어 두었던 NG도 실제 스텝 11 기준에서는 두 모델이 거절했다. 이는 초기 원본 STFPM에서 다른 스텝까지 자주 PASS하던 현상과 대비되는 관찰이다. 다만 원본 STFPM의 전체 6개 기종·13~15스텝과 최신 ROI 모델의 C003 1~12스텝은 평가 범위가 달라 정확한 동일 조건 성능 비교는 아니다.

남은 한계는 명확하다. **미세한 문자 하나 누락**은 C009 스텝 3의 확정 NG 사례에서 여전히 정상 분포 안으로 들어오는 경우가 있다. ROI가 없으면 두 임베딩 모델 모두 점수를 낼 수 없다. 최신 두 모델의 첫 교차 스텝 시험은 모델 선택에 사용된 `val_step`을 재사용한 분석이다. 이후 C003·C009의 U-Net에는 별도의 보류 test를 적용했으며 그 결과는 아래 7절에 적었다. 원본 이미지 파이프라인의 test 결과를 최신 ROI 모델의 test 성능으로 옮겨 해석할 수 없다. 현재 표본만으로 모든 NG 유형의 검출률을 주장하지 않는다.


## 7. 보류 test: 분류→ROI→U-Net 전체 파이프라인

현재 정상 수용률·다른 스텝 거절률은 **C003의 선택 U-Net `up1` 모델**에 대해 보류 test **2,280장**만으로 계산했다. C009 정상 test는 이 지표에서 제외했다. 기종별 ResNet18 분류기의 90도 네 방향 logits를 평균하고, Faster R-CNN은 클래스 결과를 버리고 최고 점수 박스만 사용했다. ROI 크기 조절에는 정답 스텝 대신 **분류기 예측 스텝**을 사용했다. 가중치·정상 저장소·`val_normal` p99 임계값은 변경하지 않았다. test 시리얼은 학습·검증 및 검출기 라벨 폴더와 겹치지 않는다.

| 정상 사진 | 스텝 분류 정답 | ROI 검출 | U-Net 정답 스텝 PASS | 전체 정상 PASS | 다른 스텝 U-Net 거절 | 다른 스텝 전체 거절 |
|---:|---:|---:|---:|---:|---:|---:|
| 2,280 | 2,272 | 2,278 | 2,243 | **2,239 (98.20%)** | **25,077/25,080 (99.99%)** | **25,077/25,080 (99.99%)** |

`전체 정상 PASS`는 스텝 예측 일치, ROI 검출, 해당 스텝 U-Net PASS를 모두 요구한다. 다른 스텝 입력은 test 사진마다 나머지 11개 후보를 전부 시험했다. 전체 파이프라인에서 잘못된 스텝으로 PASS된 3장은 스텝 분류기와 U-Net이 모두 같은 잘못된 스텝을 수용했다. [원본·ROI 모음](../test_pipeline/unet_wrong_step_pass/README.md)에 있다.

NG 다섯 장은 test 정상 분모와 분리했다. C003 NG 세 장은 최종 FAIL이다. C009 NG 두 장은 **별도로 학습한 C009 모델**로 평가한 사례이며, 한 장 PASS·한 장 FAIL이었다. C009 NG 판정을 C003 모델의 교차 기종 성능으로 해석할 수 없다. C003의 `2EQ17023/step_7`은 ROI 검출 실패를 동반하므로 U-Net 점수로 잡았다고 세지 않는다. test 폴더의 정상 라벨 전체를 재검토한 것은 아니므로 정상 FAIL 중 숨은 NG 여부는 확정되지 않았다.
