# C003: 상위 두 ROI 모델의 다른 스텝 입력 시험

서로 다른 학습 모델 중 정상 수용률이 가장 높은 U-Net `up1`과 ROI 마스크 평균·최댓값 ResNet18 `last`를 비교했다. C003의 `val_step` 정상 이미지 1,104장(스텝 1~12, 스텝당 92장)을 **모든 스텝의 정상 분포에 각각** 입력했다. 같은 스텝은 PASS, 다른 스텝 11개는 FAIL이 기대 결과다. 두 모델은 동일한 ROI 이미지를 사용하며, 각 모델의 기존 `val_normal` 스텝별 p99 임계값을 그대로 적용했다. 점수는 해당 스텝 학습 정상 ROI의 가까운 5개와의 평균 코사인 거리다.

| 모델 | 실제 스텝 PASS | 다른 스텝 거절 | 다른 스텝 오수용 | 실제 스텝만 단독 PASS |
|---|---:|---:|---:|---:|
| U-Net `up1` | 1,097/1,104 (99.37%) | 12,143/12,144 (99.992%) | 1 | 1,097/1,104 |
| ResNet18 `last` | 1,093/1,104 (99.00%) | 12,143/12,144 (99.992%) | 1 | 1,093/1,104 |

두 모델의 유일한 다른 스텝 오수용은 동일한 `2EQ16854/step_11.jpg`를 **스텝 12**로 평가한 경우다. 이 이미지는 두 모델 모두 실제 스텝 11에서는 FAIL이었다. 다른 스텝은 두 모델 모두 전부 거절했다.

**라벨 재확인:** 사용자는 이 사진이 기존 정상 목록에 섞여 있던 NG라고 확인했다. 위 표는 시험 당시 데이터 라벨에 따른 원래 집계다. 이 한 장을 정상 분모에서 빼면 확인된 정상 1,103장 중 자기 스텝 PASS는 U-Net **1,097장(99.46%)**, ResNet18 **1,093장(99.09%)**이다. 이 정상 사진들을 다른 스텝에 넣은 **12,133건은 두 모델 모두 전부 거절**했다. 새 NG는 예상 스텝 11에서는 두 모델 모두 FAIL이지만, 스텝 12 기준에서는 PASS이므로 예상 스텝 없이 아무 PASS나 수용하는 방식으로 판정해서는 안 된다.

이 결과는 **스텝 불일치 거절 성능**을 보여준다. 작은 부품 결함이나 NG 검출 성능을 뜻하지 않는다. 모델 선택에 사용된 `val_step` 이미지로 한 후속 분석이며, 별도로 보류한 `test` 분할은 사용하지 않았다. 이미지별 판정은 `per_image.csv`, 모든 스텝 조합의 건수는 `summary.json`에 있다.
