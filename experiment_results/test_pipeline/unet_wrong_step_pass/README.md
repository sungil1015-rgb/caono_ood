# U-Net 단독 다른 스텝 오수용 이미지

테스트 정상 폴더 이미지 **3장**에서 **3건**의 잘못된 스텝 PASS가 있었다. 이 중 **3건**은 스텝 분류 결과까지 같은 잘못된 스텝이어서 최종 파이프라인도 PASS했다.

`original/`은 원본 복사본, `roi/`는 검출 뒤 모델에 들어간 ROI 복사본이다. 파일명의 `actual`은 폴더상 실제 스텝, `pass`는 U-Net이 잘못 수용한 스텝이다. `manifest.csv`의 `predicted_step`은 별도 스텝 분류기 결과다. 갤러리는 원본에 검출 상자를 그려 ROI와 나란히 보여준다.

정상 폴더의 모든 이미지가 사람에게 확인된 정상이라는 뜻은 아니다. 또한 이 목록은 U-Net 단독 기준이므로, 스텝 분류기가 올바르면 최종 파이프라인에서는 대부분 거절된다.
